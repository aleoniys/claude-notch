# Claude Notch

Маленький «чубчик» зверху екрана Windows, як Dynamic Island на Mac. Показує, що зараз робить Claude Code.

**English:** [README.md](README.md)

> Неофіційний інструмент. Anthropic його не створювала, не пов'язана з ним і не схвалювала. «Claude» — торгова марка Anthropic.

## Що показує

**Пігулка зверху** змінюється залежно від того, що робить Claude Code:

| Стан | Пігулка |
|---|---|
| Працює | поточна дія, наприклад `›_ PowerShell Run tests` |
| Думає | `думає •••` |
| Щойно закінчив | `✓ готово · чекає на тебе`, доки не відкриєш панель або 3 хвилини |
| Нічого не робить | тільки іконка і кільце ліміту за 5 годин |

**Наведи мишку на пігулку**, і відкриється панель, де видно:
- проєкт, модель, гілку і статус;
- ліміт плану за 5 годин і за тиждень, з часом до скидання;
- заповнення контексту, а після 80% підказку про `/compact`;
- агентів поточної сесії: працює чи готово, час і токени;
- встановлені навички, плагіни, MCP і твоїх агентів;
- скільки токенів витрачено сьогодні.

У значка в треї є меню: відкрити панель, сховати чубчик, запуск з Windows, вийти.

## Приватність

Усе читається з локальних файлів. Нічого про тебе чи твої сесії нікуди не надсилається.

Віджет робить лише два мережеві запити:
- **Перевірка оновлень.** Раз на добу він завантажує `version.json` з цього репозиторію. Вимкнути можна через `"check_updates": false` у `config.json`.
- **Кнопка ↻.** Вона запускає `claude -p /usage`, локальну команду Claude Code. Модель вона не викликає і ліміт не витрачає.

| Файл | Що звідти береться |
|---|---|
| `~/.claude/projects/**/*.jsonl` | логи сесій |
| `~/.claude.json` | лише `cachedUsageUtilization`, `mcpServers` і `projects`. Токен входу з цього ж файлу не читається. |
| `~/.claude/skills`, `~/.claude/plugins/installed_plugins.json`, `~/.claude/agents` | навички, плагіни, агенти |

Відсотки ліміту ті самі, що зберігає сам Claude Code після перевірки плану. Вони оновлюються, поки Claude Code працює.

## Встановлення

**Що потрібно:**
- Windows 10 або 11. Заокруглені кути будуть лише на Windows 11.
- [Python 3.10+](https://www.python.org/downloads/). Під час встановлення постав галочку «Add to PATH».
- Microsoft Edge WebView2. У Windows 11 він уже є.

**Кроки:**

```powershell
git clone https://github.com/aleoniys/claude-notch.git
cd claude-notch
powershell -ExecutionPolicy Bypass -File install.ps1
```

Скрипт:
1. ставить `pystray`, `Pillow` і `pywebview`;
2. додає **Claude Notch** у меню «Пуск»;
3. запускає віджет.

Щоб віджет стартував разом з Windows: правий клік по значку в треї → **Запускати з Windows**.

**Запуск вручну:** `pythonw app.py`. Друга копія не запуститься, якщо перша вже працює.

## Мова

Мова визначається за мовою Windows. Є English, українська, polski, Deutsch, español, français, português.

Змінити мову можна:
- кнопкою **🌐** внизу панелі, вона перемикає на наступну мову;
- пунктом **Мова** в меню значка в треї.

Вибір зберігається в `config.json`.

## Оновлення

Раз на добу віджет перевіряє, чи є в цьому репозиторії новіша версія. Якщо є, у панелі та в меню трею з'являється кнопка **«Оновити до x.y.z»**.

Без твого кліку нічого не ставиться. Після кліку віджет:
1. робить `git pull`, якщо ставили через git, або завантажує ZIP;
2. зберігає твої `config.json` і `custom-icon.png`;
3. перезапускається.

**Як випустити нову версію:** збільш `version` у `version.json` і запуш у `main`.

Щоб додати свою мову, скопіюй блок `en` у `i18n.json`, переклади його, як ключ постав код мови і відкрий pull request.

## Своя іконка

Поклади поруч з `app.py` файл `custom-icon.png` і перезапусти віджет. Найкраще підходить квадратна картинка з прозорим фоном.
